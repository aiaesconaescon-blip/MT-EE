ระบบซิงค์ 2 ทางแบบ Hybrid: เชื่อมต่อ Sheet แรก (ดูงานใหม่) + Sheet สอง (บันทึกสถานะ)
เพื่อให้เพื่อนทุกคนเปิดดูผ่าน GitHub Pages แล้วเห็นงานใหม่และสถานะตรงกัน 100%
=============================================================================

โครงสร้างการทำงาน (Hybrid Sync Architecture):
1. Sheet แรก (Sheet หลักของส่วนกลาง/สาขา - สิทธิ์ดูอย่างเดียว):
   - ทำหน้าที่เป็น Master Source: ทุกครั้งที่เปิด Dashboard หรือกดปุ่ม 'อัปเดตข้อมูลจากชีต' 
     ระบบจะดึงข้อมูลใบแจ้งซ่อมทั้งหมดจาก Sheet แรกเข้ามาเสมอ หากมีงานใหม่เพิ่มเข้ามาใน Sheet แรก
     แดชบอร์ดก็จะเห็นงานใหม่ทันทีแบบ Realtime!

2. Sheet สอง (Sheet สำหรับบันทึกงานของทีมเรา - ติดตั้ง Google Apps Script):
   - ทำหน้าที่เป็น Cloud Database: เก็บข้อมูลที่ทีมเราเป็นคนอัปเดต เช่น
     * JOB NO.
     * ผู้รับผิดชอบ (ช่างเจ, ช่างเมย์, ช่างหนุ่ม, ช่างตุ้ย, งานระบบ)
     * ชื่อ ผรม. ที่เข้าดำเนินการ
     * สถานะหน้างาน (เปิดJOB, Add Budget, Add BOM, รอPO, ฯลฯ)
     * ช่องทางติดต่อ ผรม. / วันนัดหมาย
     * หมายเหตุเพิ่มเติม

3. การประกบข้อมูลอัตโนมัติ (Auto-Merge by No.):
   - เมื่อเปิด Dashboard ระบบจะดึงงานทั้งหมดจาก Sheet แรก
   - แล้วนำข้อมูลการแก้ไขล่าสุดจาก Sheet สอง มาประกบเข้าด้วยกันตาม 'เลขแจ้งซ่อม (No.)' ทันที
   - หากมีการแก้ไขใน Dashboard -> ข้อมูลจะวิ่งไปบันทึกลงใน Sheet สองทันที
   - หากมีการแก้ไขใน Sheet สองโดยตรง -> Dashboard ก็จะดึงข้อมูลที่แก้ไขนั้นมาแสดงผลทันทีเช่นกัน!

ขั้นตอนการสร้าง Sheet สอง และเปิดระบบซิงค์ (ทำเพียงครั้งเดียว):
-----------------------------------------------------------------------------
ขั้นตอนที่ 1: นำเข้าไฟล์ตารางงานขึ้น Google Sheets (สร้างเป็น Sheet สอง)
1. เปิดเบราว์เซอร์ เข้าไปที่ https://sheets.new (เพื่อเปิด Google Sheet ใหม่)
2. ตั้งชื่อไฟล์ Google Sheet เช่น: 'ตารางงานซ่อมคงค้าง AESCON GBH (สำหรับทีมงาน)'
3. ไปที่เมนู 'ไฟล์' (File) > 'นำเข้า' (Import) > แถบ 'อัปโหลด' (Upload) > กด Browse
4. เลือกไฟล์:
   'D:\AESCON Maintenance\Maintenance GBH\สรุปงานซ่อม ช่างเจ\ตารางงานทั้งหมด_สำหรับGoogleSheet.xlsx'
5. เลือก 'แทนที่สเปรดชีต' (Replace spreadsheet) แล้วกด 'นำเข้าข้อมูล' (Import data)

ขั้นตอนที่ 2: วางโค้ด Google Apps Script
1. ในหน้า Sheet สองที่เพิ่งสร้าง ไปที่เมนู: 'ส่วนขยาย' (Extensions) > 'Apps Script'
2. ลบโค้ดเดิมในนั้นออกทั้งหมด
3. เปิดไฟล์ 'google_apps_script.js' คัดลอกโค้ดทั้งหมดแล้วนำไปวางในหน้าต่าง Apps Script
4. กดปุ่มไอคอน 'บันทึก' (รูปแผ่นดิสก์ 💾 หรือกด Ctrl+S)

ขั้นตอนที่ 3: เผยแพร่เว็บแอป (Deploy Web App)
1. ที่มุมขวาบน กดปุ่มสีน้ำเงิน 'ทำให้ใช้งานได้' (Deploy) > เลือก 'การทำให้ใช้งานได้ใหม่' (New deployment)
2. เลือกประเภทเป็น 'เว็บแอป' (Web app)
3. กำหนดค่า:
   - ดำเนินการในฐานะ (Execute as): 'ฉัน' (Me)
   - ผู้มีสิทธิ์เข้าถึง (Who has access): 'ทุกคน' (Anyone)  <-- *สำคัญมาก ต้องเลือกทุกคน
4. กด 'ทำให้ใช้งานได้' (Deploy) และกดอนุญาตสิทธิ์ (Authorize access)
5. คัดลอก 'URL ของเว็บแอป' (Web App URL) ที่ลงท้ายด้วย /exec เก็บไว้

ขั้นตอนที่ 4: นำ URL มาใส่ใน Dashboard และอัปโหลดขึ้น GitHub
1. ในหน้า Dashboard คลิกปุ่ม '[ 🔄 ซิงค์ 2 ทาง (Google Sheet) ]' ที่แถบเมนูด้านบนขวา
2. วาง URL ที่ได้ลงในช่อง แล้วกด 'บันทึกการเชื่อมต่อ'
3. หรือส่ง URL ให้ผม เพื่อฝังเป็นค่าเริ่มต้นใน index.html ให้ทุกคนที่เปิด GitHub Pages ซิงค์อัตโนมัติ
4. นำไฟล์ทั้งหมดในโฟลเดอร์ 'ไฟล์สำหรับอัพโหลดขึ้น_GitHub' ไปอัปโหลดทับใน GitHub Repository MT-EE
