เชื่อมต่อ Google Sheet สองทาง (2-Way Sync)

ยังไม่ได้เชื่อมต่อ

ให้เพื่อนๆ ใน GitHub เห็นข้อมูลอัปเดตตรงกันแบบเรียลไทม์

💡 ทำไมเพื่อนใน GitHub ถึงไม่เห็นข้อมูลที่เราอัปเดต?

เนื่องจาก GitHub Pages เป็นเว็บแบบไฟล์นิ่ง (Static Hosting) เมื่อกดบันทึก ข้อมูลจึงอยู่เฉพาะในเครื่องของเราคนเดียว หากต้องการให้เพื่อนๆ ทุกคนที่เปิดลิงก์เห็นข้อมูลอัปเดตตรงกัน และสามารถแก้ไขสถานะได้ทั้งในหน้าเว็บและใน Google Sheet ให้เชื่อมต่อผ่าน Google Apps Script ตามขั้นตอนง่ายๆ ด้านล่างนี้ครับ:

📋 ขั้นตอนการเชื่อมต่อ (ทำเพียงครั้งเดียว):

1
สร้าง Google Sheet ของทีม:

เปิด sheets.new แล้วนำเข้าไฟล์ "ตารางงานทั้งหมด_สำหรับGoogleSheet.xlsx" ที่เตรียมไว้ให้ในโฟลเดอร์

2
ใส่โค้ดใน Apps Script:

ใน Google Sheet ไปที่เมนู ส่วนขยาย (Extensions) > Apps Script แล้วคัดลอกโค้ดจากไฟล์ google_apps_script.js ไปวางแทนที่ทั้งหมดแล้วกดบันทึก

3
Deploy เป็น Web App:

กดปุ่ม Deploy (ทำให้ใช้งานได้) > New deployment เลือก Web app กำหนด Who has access เป็น Anyone (ทุกคน) แล้วคัดลอก URL ของเว็บแอปมาวางในช่องด้านล่างนี้

เมื่อเชื่อมต่อแล้ว ทุกครั้งที่มีการแก้ไขบนเว็บ ข้อมูลจะอัปเดตลง Google Sheet ทันที และเมื่อมีการแก้ไขใน Google Sheet หน้าเว็บก็จะอัปเดตให้อัตโนมัติ เพื่อนๆ ทุกคนจะเห็นตรงกัน 100%!
